# Work Mug - Productivity Companion Mini Program
A cute, interactive WeChat Mini Program that boosts focus with an emotional desk mug.

## Core Features
- Work/rest state timer
- Interactive mug with mood feedback (happy / neutral / flustered / angry)
- To-do list bulletin board
- Work score system
- LLM-powered text chat interaction

## How It Works
- Mug stays quiet during working sessions
- Responds in rest state based on work score
- Positive feedback for high productivity
- Gentle reminders for moderate work
- Negative mood for low productivity

## Controls
- Tap clock to start/stop work session
- Tap mug to interact
- Type messages to chat with the mug
